JavaScript 程序的基本结构：条件语句（if / else / switch）与循环语句（for / while / do-while）。

01

条件语句

if / else if / else

多分支条件判断

var xzx_score = 85; if (xzx_score >= 90) { // 优秀 } else if (xzx_score >= 60) { // 及格 } else { // 不及格 }
输出

switch

多值匹配，break 防止穿透

var xzx_day = 3; switch (xzx_day) { case 1: xzx_result = "周一"; break; case 3: xzx_result = "周三"; break; default: xzx_result = "其他"; }
输出

三元运算符

条件 ? 值1 : 值2

var xzx_age = 20; var xzx_status = xzx_age >= 18 ? "成年" : "未成年";
输出
02

循环语句

for 循环

初始化; 条件; 更新

for (var xzx_i = 1; xzx_i <= 5; xzx_i++) { // 执行 5 次 }
输出（1~5）

while 循环

先判断条件，再执行

var xzx_n = 5; while (xzx_n > 0) { // 倒序输出 xzx_n--; }
输出（5~1）

do-while 循环

先执行一次，再判断条件

var xzx_k = 1; do { // 至少执行 1 次 xzx_k++; } while (xzx_k <= 3);
输出
