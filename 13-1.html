CSS Grid · grid-template-areas

许镇玺 · Grid 网格布局

用命名区块一次性排布页面结构，行列自动对齐。

a头部
b主视觉 2×2
c侧边栏 3 行
d内容 2 行
e单元
f单元
.xzx_grid { display: grid; grid-template-columns: 1fr 1fr 1fr; grid-template-rows: 90px 90px 90px 90px; grid-template-areas: 'a b b' 'c b b' 'c d e' 'c d f'; gap: 12px; } .xzx_a { grid-area: a; } .xzx_b { grid-area: b; } .xzx_c { grid-area: c; } .xzx_d { grid-area: d; } .xzx_e { grid-area: e; } .xzx_f { grid-area: f; }

说明：重复出现的字母会让该区块自动跨行跨列——b 横跨 2×2， c 纵向跨越 3 行，d 跨越 2 行；其余 a、e、f 各占一格。 窄屏下通过媒体查询把区域改为一列堆叠。
