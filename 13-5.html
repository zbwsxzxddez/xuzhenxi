<!-- ① 隐藏 sprite：内联自 iconfont.js 的 symbol，fill="currentColor" -->
<svg class="xzx_sprite" aria-hidden="true">
  <symbol id="xzx_icon-shouye1" viewBox="0 0 1024 1024">
    <path fill="currentColor" d="M597.333333 768h170.666667..."/>
  </symbol>
  <symbol id="xzx_icon-faxian" ...></symbol>
  ...
</svg>

<!-- ② 固定底部导航：4 项，徽章与红点为 span 覆盖层 -->
<nav class="xzx_nav">
  <a class="xzx_nav-item xzx_active">
    <span class="xzx_nav-icon">
      <svg class="xzx_nav-svg">
        <use href="#xzx_icon-shouye1"></use>
      </svg>
    </span>
    <span class="xzx_nav-label">首页</span>
  </a>
  <a class="xzx_nav-item">
    <span class="xzx_nav-icon">
      <svg class="xzx_nav-svg"><use href="#xzx_icon-faxian"></use></svg>
      <span class="xzx_badge">5</span>   /* 数字徽章 */
    </span>
    <span class="xzx_nav-label">发现</span>
  </a>
  ...
</nav>

.xzx_nav {
  position: fixed; left: 0; right: 0; bottom: 0;
  width: 100%;                 /* 全屏宽度 */
  display: flex;
  padding-bottom: env(safe-area-inset-bottom);  /* 全面屏安全区 */
}
.xzx_nav-item { flex: 1 1 0; }   /* 4 项等分，自适应屏宽 */
.xzx_nav-svg { width: 26px; height: 26px; fill: currentColor; }
.xzx_badge {
  position: absolute; top: -6px; right: -10px;
  background: #b23c28; border-radius: 999px;
}
.xzx_dot {
  position: absolute; top: -2px; right: -5px;
  width: 8px; height: 8px; border-radius: 50%;
  background: #b23c28;
}

说明：SVG 方案 —— 从本地 font/font_5244851_6n95j09brtj/iconfont.js 取出 4 个 symbol，内联为页面顶部的隐藏 sprite，导航图标用 <use href="#xzx_icon-xxx"> 引用；path 上 fill="currentColor" 让颜色跟随 CSS color 变化。 与 13-4.html 的字体图标方案对比：同一份 iconfont 资源，两种渲染形态—— 字体走 ::before 字符编码，SVG 走矢量路径。 底导本身两种方案完全相同：fixed + 100% 全屏宽度固定、 flex:1 4 项均分、数字徽章与红点均为纯 CSS 覆盖层。
