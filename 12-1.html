CSS Custom Properties

许镇玺 · CSS 变量演示

用 CSS 自定义属性（CSS 变量）统一管理颜色、圆角与间距，一处修改、全局生效。

颜色变量

文字、边框、主色都来自 var()，切换主色时整页同步改变。

圆角变量

拖动上方“圆角”滑块，卡片、面板、代码块一起改变圆角。

间距变量

卡片之间的 gap 由 --xzx_gap 统一控制。

局部作用域变量

本容器重新定义了 --xzx_primary 与 --xzx_radius， 只影响自身及其后代，页面其他部分不受影响——这正是 CSS 变量继承与作用域的体现。
