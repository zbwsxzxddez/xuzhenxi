<!-- ① 引用下载到本地的 Font Awesome 样式表 --> <link rel="stylesheet" href="cdn/fontawesome/css/all.min.css"> <!-- ② 类名 = 字体族(fa-solid/fa-regular/fa-brands) + 图标名 --> <i class="fa-solid fa-house"></i> <i class="fa-regular fa-star"></i> <i class="fa-brands fa-github"></i> .xzx_item i { font-family: "Font Awesome 6 Free"; /* @font-face 加载的本地字体 */ font-weight: 900; /* 900 实心 solid · 400 常规 regular */ font-size: 32px; /* 文字属性缩放，任意倍数都不失真 */ color: #154943; /* 文字属性上色，无需改图片 */ } .xzx_item:hover i { color: #b23c28; }

说明：字体图标的本质是「字体文件 + 编码映射」——Font Awesome 把图标绘制进 woff2 / ttf 字体，浏览器经 @font-face 加载后， fa-house 这类类名通过 ::before 输出对应字符编码 （房子 = f015），再由字体渲染成图形。 所以图标天生具备文字特性：color 换色、font-size 缩放、font-weight 换粗细，放大也不会模糊。 本页全部资源来自本地 cdn/fontawesome/（css/all.min.css + webfonts 下 6 个字体文件），不联网。
