智能客服系统业务流程图（flowchart）

xzx_flow · 从用户提问到答案返回 / 转人工，再到 badcase 回流知识库的完整链路

flowchart TD
    A([用户提问]) --> B[接入层
鉴权 · 限流 · 敏感词初筛]
    B --> C[NLU 意图识别
实体抽取 NER]
    C --> D{置信度 ≥ 阈值?}
    D -- 是 --> E[RAG 知识库检索
查询改写 → 向量召回 → 重排]
    E --> F{命中 Top-K 证据?}
    F -- 是 --> G[LLM 基于证据
生成答案]
    F -- 否 --> H[兜底话术]
    D -- 否 --> I[转人工坐席]
    G --> J{敏感词 / 合规审查}
    J -- 通过 --> K([返回用户])
    J -- 不通过 --> H
    H --> L[(badcase 沉淀)]
    I --> L
    L --> M[(知识库
迭代更新)]
    M -.-> E

智能客服系统数据库 ER 图（erDiagram）

xzx_er · 用户 / 会话 / 消息 / 意图 / 知识条目 / 人工坐席 六个核心实体

erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--|{ MESSAGE : "包含"
    SESSION }o--o| AGENT : "可能转接"
    MESSAGE }o--|| INTENT : "命中意图"
    INTENT ||--o{ KB_ENTRY : "关联知识"
    CATEGORY ||--o{ KB_ENTRY : "分类归属"
    CATEGORY ||--o{ INTENT : "涵盖"

    USER {
        bigint user_id PK "用户ID"
        varchar nickname "昵称"
        varchar phone "手机号"
        int member_level "会员等级"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "所属用户"
        bigint agent_id FK "转接坐席(可空)"
        varchar channel "渠道 web-app-api"
        tinyint status "0进行中 1已结束"
        datetime started_at "开始时间"
    }
    MESSAGE {
        bigint msg_id PK "消息ID"
        bigint session_id FK "所属会话"
        bigint intent_id FK "命中意图(可空)"
        tinyint role "0用户 1机器人 2坐席"
        text content "消息内容"
        decimal confidence "NLU置信度"
        datetime sent_at "发送时间"
    }
    INTENT {
        bigint intent_id PK "意图ID"
        varchar intent_name "意图名称"
        bigint category_id FK "所属类目"
        decimal threshold "兜底阈值"
    }
    KB_ENTRY {
        bigint kb_id PK "知识条目ID"
        varchar question "标准问法"
        text answer "标准答案"
        bigint category_id FK "所属类目"
        tinyint source "0人工 1badcase回流"
        datetime updated_at "更新时间"
    }
    CATEGORY {
        bigint category_id PK "类目ID"
        varchar category_name "类目名称"
        bigint parent_id FK "父类目"
    }
    AGENT {
        bigint agent_id PK "坐席ID"
        varchar agent_name "坐席姓名"
        tinyint online_status "在线状态"
    }
