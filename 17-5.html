setTimeout 一次性

空闲
const id = setTimeout(fn, delay)
clearTimeout(id)  // 到点只执行一次

setInterval 周期性

空闲
const id = setInterval(fn, interval)
clearInterval(id)  // 每隔 interval 执行一次

区别总结：setTimeout 到点后只执行一次，适合延时任务（如提示框自动消失）； setInterval 每隔固定时间重复执行，适合轮询、倒计时、轮播图等场景。 两者都返回一个 ID，分别用 clearTimeout / clearInterval 取消。 JS 是单线程的，定时器回调实际由事件循环调度，若主线程被阻塞，触发时间会延后（不保证精确）。
