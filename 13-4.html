查看实现代码（字体图标 + 徽章 / 红点） 
<!-- ① 引用 font/ 目录下的 iconfont 字体 -->
<link rel="stylesheet" href="font/font_5244851_6n95j09brtj/iconfont.css">

<!-- ② 固定底部导航：4 项，徽章与红点为 span 覆盖层 -->
<nav class="xuzhenxi_nav">
  <a class="xuzhenxi_nav-item xuzhenxi_active">
    <span class="xuzhenxi_nav-icon"><i class="iconfont icon-shouye1"></i></span>
    <span class="xuzhenxi_nav-label">首页</span>
  </a>
  <a class="xuzhenxi_nav-item">
    <span class="xuzhenxi_nav-icon">
      <i class="iconfont icon-faxian"></i>
      <span class="xuzhenxi_badge">5</span>   /* 数字徽章 */
    </span>
    <span class="xuzhenxi_nav-label">发现</span>
  </a>
  ...
</nav>

.xuzhenxi_nav {
  position: fixed; left: 0; right: 0; bottom: 0;
  width: 100%;                 /* 全屏宽度 */
  display: flex;
  padding-bottom: env(safe-area-inset-bottom);  /* 全面屏安全区 */
}
.xuzhenxi_nav-item { flex: 1 1 0; }   /* 4 项等分，自适应屏宽 */
.xuzhenxi_badge {
  position: absolute; top: -6px; right: -10px;
  background: #b23c28; border-radius: 999px;
}
.xuzhenxi_dot {
  position: absolute; top: -2px; right: -5px;
  width: 8px; height: 8px; border-radius: 50%;
  background: #b23c28;
}

说明：字体图标方案 —— iconfont 把 4 个图标绘制进 woff2/ttf 字体， .icon-xxx 类名经 ::before 输出字符编码 （首页 eaf0 / 发现 e631 / 微信 e608 / 我的 e8c6）， 因此图标可用 color 直接上色、font-size 控制大小。 底导 fixed + 100% 全屏宽度固定，flex:1 让 4 项在任意屏宽下均分； 数字徽章与右上角红点都是相对图标定位的纯 CSS 覆盖层，与图标实现方式无关。 资源来自本地 font/font_5244851_6n95j09brtj/，不联网。
